# "Берегись автомобиля"

Большая языковая модель, способная генерировать текст для мемов формата Impact.

Проект реализует **обучение модели**, **расположение текста на картинке в стандарте формата**, **возможность установки приложения как сервиса** и **большое количество утилит внутри самого проекта**.

### Особенности
*   **Стек:** Python 3.10+, PyTorch, Transformers, pandas.
*   **LLM:** В своей основе использует зафайнтьюненную `ruGPT3-small` на датасете анекдотов, новостных пабликов, книгах Ницше и Сартра.
*   **Генерация и работа с картинками:** Разделение текста по количеству символов, настройка температуры, возможность выбора модели, формирование картинок и их оптимизация в размере.
*   **Настраиваемость**: В config.py можно выбрать режим по умолчанию и провести тонкую настройку каждого режима.
